Import notes

    Curves

    Assign the same antigen / plot group to curves you want on one graph.

    Assign concentration labels

    Applies to files with a recognised well in the filename. Labels do not change the data or perform a fit.

    0 rows selected

    Click row numbers to pick any combination; Shift-click adds a range. Selected-row plots use your chosen rows, including rows with Use unchecked. The figure and exports follow the display choice below.

    Select cells to edit
    Curve names, antigens and export selection

    Drag or Shift-click to select cells. Click a column heading to select its labels. Copy/paste with Excel; paste one value to fill a selection. Arrow keys and Tab move between cells; Enter moves down. Double-click or F2 edits text. Ctrl/⌘ Z undoes label edits. Selections and bulk edits apply only to visible rows.

    Plate reference Optional

    Paste a plate layout into any well. This is a naming reference; it does not assign labels automatically.

    Figure

    The selected curves, with their own time values.

    Include at least one curve to create a figure.
    Figure settings

    Axis limits crop the figure only. Exports retain all selected data points. The phase marker uses the displayed time basis.

    Take your work with you

    SVG and PNG export the displayed figure. Excel and Prism export every included table. PZFX contains XY data tables; figure styling is saved in the SVG/PNG.
